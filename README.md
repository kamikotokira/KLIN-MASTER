# Клин-мастер
https://kamikotokira.github.io/KLIN-MASTER/

Сайт клининговой компании: услуги, цены и расчёт стоимости уборки. Сделан на HTML, CSS и JavaScript.


## Возможности

- три вида уборки: поддерживающая, генеральная, после ремонта;
- быстрый расчёт по площади;
- ориентировочное время уборки;
- подробный калькулятор с дополнительными услугами;
- памятка подготовки к приезду клинера;
- расчёт стоимости без перезагрузки страницы;
- проверка полей формы;
- сообщение о принятой заявке;
- фотографии рабочих моментов;
- появление секций при прокрутке через animate.css;
- адаптивная вёрстка для компьютера и телефона.

## Расчёт стоимости

Базовая стоимость:

| Услуга | Цена за м² | Минимум |
|---|---:|---:|
| Поддерживающая | 150 ₽ | 2 800 ₽ |
| Генеральная | 250 ₽ | 5 000 ₽ |
| После ремонта | 320 ₽ | 6 500 ₽ |

Дополнительно:

- мытьё окон — 1 200 ₽;
- духовка — 800 ₽;
- холодильник — 600 ₽;
- балкон — 900 ₽.

Итог = максимальное значение из «площадь * ставка» и минимальной цены, плюс выбранные дополнительные услуги.

## Технологии

- HTML5;
- CSS3;
- JavaScript (ES2015+);
- шрифт Montserrat подключается через @import из Google Fonts;
- animate.css 4.1.1 для появления секций при прокрутке;
